# Glossaire – Pulse Motion

Les mots du métier de ce projet, avec une définition commune. L'IA et vous les employez dans le même sens, dans les documents comme dans le code.

## Vocabulaire

**Genre** :
Ce que la vidéo fait pour son public : présentation de produit, storytelling, formation, publication sociale. Le genre fixe la structure et le rythme du récit, indépendamment de l'apparence.
_À éviter_ : type de vidéo, format (réservé aux proportions de l'image)

**Style** :
L'apparence d'une vidéo et sa façon de bouger : couleurs, typographie, formes, textures, courbes de mouvement. Un style est un point de départ personnalisable, applicable à n'importe quel genre.
_À éviter_ : thème, look, template

**Détourage** :
Le fait d'isoler une personne ou un objet filmé de son arrière-plan, pour l'intégrer dans une animation. Il se fait sur l'ordinateur, par une IA locale ou par retrait d'un fond vert.
_À éviter_ : suppression de fond, extraction, matting

**Parcours** :
La manière dont la personne est accompagnée pendant la fabrication d'une vidéo, choisie au départ. Le parcours rapide demande un seul accord (le déroulé) ; le parcours accompagné en demande trois (le déroulé, le style, la vidéo finale).
_À éviter_ : mode, niveau

**Charte** :
L'identité propre de la personne ou de son client : logo, couleurs, polices. La charte s'applique à un style pour le personnaliser.
_À éviter_ : branding, identité visuelle, marque

**Déroulé** :
La liste ordonnée des scènes d'une vidéo, avec pour chacune son texte, ce qu'on y voit et sa durée. C'est le seul accord demandé dans le parcours rapide.
_À éviter_ : script, storyboard, plan

**Modèle** :
Une vidéo réussie transformée en gabarit, dont certaines zones (textes, chiffres, charte, images) sont à remplir pour produire des variantes.
_À éviter_ : template, gabarit

**Variante** :
Une vidéo produite à partir d'un modèle, avec ses propres valeurs (par exemple un client et ses couleurs).
_À éviter_ : déclinaison, version

**Série** :
L'ensemble des variantes d'un même modèle produites ensemble, à partir d'un tableau ou d'une liste donnée dans la conversation.
_À éviter_ : lot, batch
