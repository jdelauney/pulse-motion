/pulse-motion:outils

Vérifier que l'ordinateur est prêt pour les vidéos et installer ce qui manque (ffmpeg, la transcription, Python), avec votre accord. Ne crée ni ne modifie aucune vidéo.

    Description

    Pulse Motion s'appuie sur quelques logiciels de votre ordinateur. Cette commande vous dit simplement ce qui est prêt et ce qui manque, puis installe ce qui manque, avec votre accord. Elle fonctionne dans n'importe quel dossier, avec ou sans vidéo.

    Elle commence par la version de Pulse Motion installée (« Pulse Motion 0.16.0 est installé »), puis montre un tableau :

    OutilÀ quoi il sert
    Chrome ou EdgeRegarder la vidéo, la contrôler, l'exporter.
    ffmpegUn MP4 de qualité avec un son propre. Sans lui, l'export se fait dans le navigateur.
    PythonNécessaire à la transcription.
    La transcriptionCaler les sous-titres et les animations sur les vrais mots de votre voix. Facultative.
    La voix de l'ordinateurLa voix provisoire, avant d'enregistrer la vôtre.

    Chaque outil manquant est suivi de ce que vous pouvez faire, par exemple : dites « installe ffmpeg ».

    Pourquoi l'utiliser

    • Vous savez d'un coup d'œil si tout est prêt, avant un premier export ou un premier enregistrement.
    • Rien ne s'installe sans votre accord. Pulse Motion vous demande « Installer (Recommandé) » ou « Pas maintenant », une installation à la fois.
    • Vous n'avez rien à taper sur Windows et sur Mac : Pulse Motion lance lui-même l'installation. Sur Linux, il vous donne la ligne à taper.
    • Vos vidéos ne sont pas touchées. Les outils s'installent sur l'ordinateur ; aucune vidéo n'est créée ni modifiée.

    Quand l'utiliser

    1. 1 Créer
    2. 2 Retoucher
    3. 3 Exporter
    4. 4 Personnaliser
    • Avant votre première vidéo, une fois le plugin installé (voir les prérequis).
    • Avant /pulse-motion:exporter, pour installer ffmpeg et obtenir un export fidèle.

    • Quand un message parle d'un outil qui manque.

    Comment la lancer

    /pulse-motion:outils

    Seule, elle vérifie l'ordinateur. Pour installer un outil, dites-le juste après le nom ou dans la conversation.

    /pulse-motion:outils installe ffmpeg
    /pulse-motion:outils installe la transcription

    Ce que vous pouvez demander

    Vous ditesCe qui se passe
    « vérifie mon ordinateur », « est-ce que tout est prêt pour l'export ? »La version de Pulse Motion et le tableau des outils, prêts ou manquants.
    « installe ffmpeg »Pulse Motion explique en une phrase à quoi il sert, demande votre accord, l'installe, puis vérifie qu'il est bien là.
    « installe la transcription »Trois choix : « Installer (Recommandé) », environ 800 Mo à télécharger une fois ; « Version légère », 250 Mo, un peu moins précise ; « Pas maintenant ». Si Python manque, il est installé d'abord, avec votre accord.
    « installe Python »Seulement s'il manque ou s'il est trop ancien : Pulse Motion demande votre accord, l'installe, puis vérifie.

    Les mêmes outils, installés à la main, sont décrits dans les prérequis.

    Ce qu'elle produit

    • Un état des lieux en mots simples : ce qui est prêt, ce qui manque, et comment l'obtenir.
    • Les outils installés sur l'ordinateur, si vous l'acceptez : ffmpeg, Python, la transcription. Rien dans votre vidéo ne change.
    • La suite à donner : l'action qui attendait l'outil (l'export, l'enregistrement d'une voix), sinon la création d'une vidéo avec /pulse-motion:creer.

    Risques et précautions

    • La transcription est un gros téléchargement. Environ 800 Mo (250 Mo en version légère), une seule fois. L'installation prend quelques minutes : Pulse Motion vous prévient et attend la fin.
    • Un outil tout juste installé peut rester invisible. L'ordinateur ne voit un nouveau logiciel qu'au redémarrage de Claude Code. Relancez-le, puis redemandez « vérifie mon ordinateur ».
    • Sur Linux, c'est vous qui tapez la ligne d'installation, dans un terminal, parce qu'elle demande votre mot de passe. Pulse Motion attend que vous lui disiez que c'est fait, puis vérifie.
    • Le navigateur et le micro ne s'installent pas d'ici. Chrome ou Edge s'installent depuis leur site. Le micro se teste dans le studio de voix : demandez « j'enregistre la scène 1 » quand une vidéo est ouverte.

    Conseil : ffmpeg et la transcription sont facultatifs. Sans ffmpeg, l'export se fait dans le navigateur ; sans transcription, les mots de la voix sont calés au mieux. Tout le reste fonctionne.

    Problèmes et solutions

    ffmpeg est toujours absent après l'installation

    L'ordinateur ne le voit qu'au redémarrage de Claude Code. Fermez Claude Code, relancez-le, puis redemandez « vérifie mon ordinateur ».

    Python reste introuvable

    Même cause : relancez Claude Code pour finir l'installation, puis redemandez « installe la transcription ».

    « Python est trop ancien »

    La transcription a besoin d'une version plus récente. Demandez « installe Python » : Pulse Motion installe la version qu'il faut, avec votre accord.

    L'installation de la transcription a échoué

    Pulse Motion vous dit pourquoi, simplement. Tout fonctionne sans elle : les mots de la voix sont calés au mieux. Vous pourrez réessayer plus tard.

    Chrome ou Edge sont signalés absents

    Installez l'un des deux depuis son site, puis redemandez « vérifie mon ordinateur ». Voir Chrome ou Edge.

    « node » introuvable

    Node.js n'est pas installé : Pulse Motion ne peut rien vérifier sans lui. Installez-le en version LTS depuis nodejs.org (programme d'installation), puis relancez Claude Code. Voir les prérequis.

    Installer

    pulse-motion whisper installer

    L'installation prend quelques minutes, je vous préviens dès qu'elle est finie.

    ✅ Fait : la transcription est installée. Votre vidéo a déjà des prises de voix : voulez-vous que je recale leurs mots ? 📄 Fichiers : rien dans votre vidéo n'a changé ; les outils sont installés sur l'ordinateur.

    Commandes liées

    • /pulse-motion:exporter : l'export fidèle, avec ffmpeg.
    • /pulse-motion:voix : importer un enregistrement de toute la vidéo, recaler les mots.
    • /pulse-motion:creer : créer une vidéo une fois l'ordinateur prêt.
