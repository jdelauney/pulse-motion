Étape 1 · Créer

/pulse-motion:filmer

Filmer une application web ou un site pour un tutoriel, ou partir d'une vidéo ou de captures de votre écran (« filme comment on crée une facture sur app.exemple.fr », « j'ai enregistré mon écran », « floute les noms des clients »).

    Description

    C'est la commande des tutoriels de logiciel : montrer comment on fait dans une application (« on va dans Factures, on clique sur Nouvelle facture, on tape le client, on enregistre »). Vous racontez le parcours avec vos mots ; Pulse Motion le fait lui-même dans l'application, étape par étape, et la filme.

    1. Vous décrivez le parcours, comme à un collègue, et vous donnez l'adresse de départ. Pulse Motion vous le relit en phrases numérotées : vous validez ou vous corrigez.
    2. Pour un site en ligne, il vous demande votre accord, avec le nom du site. Si l'application demande un identifiant, vous vous connectez vous-même, dans une fenêtre qui s'ouvre sur votre écran.
    3. Il filme : une image de chaque état de l'application, les courtes réactions après chaque clic, et la position de chaque clic. Quelques secondes par étape.
    4. Il regarde le résultat avec vous : une planche, une image par étape. Il vous signale ce qui semble personnel et propose de le flouter.
    5. Vous choisissez la prise que vous gardez, ou vous refilmez.
    6. Le film entre dans la vidéo : une scène pour une à trois étapes. Le pointeur, les clics, les zooms et le projecteur sont ajoutés par Pulse Motion, après le tournage.

    Elle sait aussi partir d'une vidéo de votre écran (un logiciel installé, filmé avec l'outil de votre ordinateur), d'une animation (un GIF) ou de captures d'écran : le même pointeur, les mêmes zooms et le même projecteur s'y posent.

    Vous pouvez la lancer seule, pour ajouter un film à une vidéo qui existe déjà. /pulse-motion:creer l'appelle aussi de lui-même pour un sujet de tutoriel.

    Pourquoi l'utiliser

    • Tout se retouche sans refilmer. Le pointeur, les zooms, le projecteur et le temps entre deux clics sont posés après coup : « le pointeur va trop vite », « zoome sur le bouton » se demandent en une phrase.
    • Le film est gardé avec la vidéo. Une fois filmée, l'application n'est plus jamais consultée : ni l'aperçu, ni l'export n'ont besoin d'internet, et deux exports donnent exactement les mêmes images.
    • Les données personnelles sont floutées dans les images mêmes, au moment du tournage : adresses électroniques, téléphones, IBAN, numéros de carte. Aucune image nette n'est gardée.
    • Votre mot de passe reste à vous. Pulse Motion ne le tape jamais, ne le voit pas et ne l'écrit nulle part, même si vous le donnez dans la conversation.
    • Une prise ratée se refait. Chaque tournage est une nouvelle prise ; c'est vous qui choisissez celle qui va dans la vidéo.

    Ce qu'elle produit

    • Le film, rangé dans le dossier de la vidéo, sous films/ : les images de chaque étape, déjà floutées, et la position de chaque clic. Chaque tournage y ajoute une prise.
    • Une planche par prise : une image par étape, avec la cible du clic et le nombre de zones floutées. Pulse Motion la regarde avec vous.
    • Des scènes filmées dans la vidéo, une pour une à trois étapes, montrées dans un cadre de navigateur (ou de téléphone, de tablette, de fenêtre).

    Ce qui est gardé sur votre ordinateur, et ce qui ne l'est pas, est détaillé dans la section Confidentialité des concepts.

    Risques et précautions

    • Les clics sont réels. Pulse Motion fait vraiment les actions dans l'application : une facture enregistrée est enregistrée, un message envoyé est envoyé, et rien n'est annulé ensuite. Utilisez un compte de démonstration si vous en avez un.
    • Le flou automatique ne reconnaît pas tout. Il voit les adresses électroniques, les téléphones, les IBAN, les numéros de carte et de sécurité sociale, les champs d'adresse et de date de naissance. Les noms, les visages ou les montants, c'est Pulse Motion qui vous les signale en regardant la planche, et vous qui décidez.
    • Un flou ajouté après coup est définitif dans cette prise : pour l'enlever, il faut refilmer. Une vidéo déjà exportée avant ce flou garde l'image nette : refaites l'export.
    • Un seul site par tournage. L'accord vaut pour ce site ; si la page veut emmener ailleurs, la navigation est bloquée et Pulse Motion vous le dit.
    • Ne touchez pas à la fenêtre pendant le tournage, quand elle est visible (après une connexion) : quelques secondes par étape.

    Conseil : commencez par l'appli d'essai (« montre-moi sur l'appli d'essai ») : vous voyez tout le parcours, connexion et flou compris, sans toucher à une vraie application.

    Problèmes et solutions

    Pulse Motion ne trouve pas le bouton ou le champ

    La prise s'arrête à cette étape. Pulse Motion vous dit ce qu'il voit à la place, et vous montre l'image. Décrivez la cible autrement, avec le texte qui s'affiche vraiment (« le bouton Créer »), sa position (« le deuxième Modifier ») ou l'endroit (« dans la fenêtre »), puis refilmez. Les actions déjà faites ne sont pas annulées.

    La page me redemande de me connecter

    La connexion a expiré, ou le site demande un identifiant que Pulse Motion n'a pas. Répondez « je dois d'abord me connecter » : la fenêtre s'ouvre, vous vous connectez, puis vous dites « c'est fait ».

    On ne voit pas le chargement de la page

    Par défaut, Pulse Motion passe d'une page à l'autre par un fondu. Dites « on ne voit pas le chargement » : la prochaine prise garde les images du chargement.

    Ma vidéo de l'écran est refusée

    Son format n'est pas lisible par le navigateur de votre ordinateur. Installez ffmpeg avec /pulse-motion:outils, puis redonnez le fichier.

    Ma vidéo de l'écran dure plus de 3 minutes

    Pulse Motion vous demande le passage à garder : le début et la fin, en minutes et secondes (« de 0:12 à 1:05 »).

    Pulse Motion signale une vidéo lourde

    Au-delà de 25 Mo d'images dans la page, il vous le dit avant l'export. Supprimez les prises inutiles, raccourcissez les réactions, ou montrez moins d'étapes par scène.

    « Chrome ou Edge est introuvable »

    Le tournage passe par Chrome ou Edge. Installez l'un des deux, puis vérifiez avec /pulse-motion:outils. Voir les prérequis.

    Commandes liées

    • /pulse-motion:creer : un tutoriel complet, à partir du modèle « Tutoriel logiciel ».
    • /pulse-motion:retoucher : placer le film dans la vidéo, régler le pointeur, les zooms, le projecteur, le cadre.
    • /pulse-motion:voix : enregistrer votre voix, ou garder celle de votre vidéo de l'écran.
    • /pulse-motion:outils : installer ffmpeg pour importer tous les formats de vidéo.
    • /pulse-motion:exporter : une vidéo filmée s'exporte comme les autres.
