Étape 3 · Exporter

/pulse-motion:exporter

Exporter la vidéo en MP4 réglé pour son usage (le web, les réseaux sociaux, une réunion, un monteur, un courriel), fabriqué sur l'ordinateur, pour la publier ou l'envoyer.

    Description

    La page animée se regarde dans un navigateur ; le fichier MP4, lui, se publie partout : réseaux sociaux, plateforme de formation, courriel, YouTube. Cette commande le fabrique sur votre ordinateur, sans rien envoyer en ligne.

    Elle prend la vidéo telle qu'elle est : elle ne modifie rien. Vous dites à quoi sert la vidéo (« pour LinkedIn », « pour l'envoyer par courriel ») et Pulse Motion choisit les réglages : la taille de l'image, sa netteté, le poids du fichier. Elle contrôle d'abord la vidéo, puis choisit la meilleure façon d'exporter :

    ModeQuandCe que vous obtenez
    Export fidèleffmpeg est installé (Pulse Motion vous le propose une fois)Les vraies images du navigateur, image par image, et le son au bon niveau, vérifié. Le temps dépend de l'usage (voir le tableau ci-dessous).
    Export dans le navigateurSans ffmpeg, ou si vous refusez de l'installerUn MP4 fabriqué directement dans Chrome ou Edge, sans rien installer. Quelques effets avancés y sont moins bien rendus.

    Les deux exports ont exactement le même son que l'aperçu : la musique, la voix et les bruitages sont mélangés une seule fois, dans la page, et ramenés au niveau des plateformes de diffusion. Les couleurs de la vidéo sont celles de la page, dans les lecteurs courants (Chrome, Safari, VLC, PowerPoint).

    Les usages

    Chaque usage donne son propre fichier : exporter pour le courriel n'écrase pas la version pour le web. Poids et temps mesurés sur les deux vidéos témoins (une minute et trois minutes) avec un ordinateur de bureau récent ; comptez davantage sur un portable.

    Après un premier export, un autre usage ne refait aucune image : il repart des images déjà capturées. La version pour le courriel vise moins de 10 Mo (ou la taille que vous dites, « moins de 25 Mo pour Teams ») ; si la vidéo est trop longue pour tenir, Pulse Motion vous le dit avant de commencer, avec la taille qu'il faudrait. La version de travail est faite vite, par la carte graphique quand elle sait le faire : elle sert à vérifier, jamais à publier.

    Dans l'aperçu, le bouton MP4 de la barre de lecture propose quatre usages : Web, Réseaux, Présentation, Courriel.

    Les chapitres ne sont joints que si vous les avez demandés (« ajoute des chapitres », une retouche) ; ils sont alors aussi intégrés au MP4 quand ffmpeg est installé, et YouTube les montre à partir de trois. Les crédits accompagnent chaque export : polices, musique, voix, images et sons, avec leur licence. Un fichier que vous avez importé sans dire d'où il vient y est marqué « à préciser » : dites-le simplement (« la musique vient de Pixabay »).

Pour une vidéo verticale faite pour TikTok, les Shorts ou les Reels, dites-le (une retouche) : le contrôle vérifie alors que rien ne passe sous les boutons de l'application, et les sous-titres se placent au-dessus. Dans l'aperçu, la touche Z montre cette zone.

    Pourquoi l'utiliser

    • Tout reste chez vous. Aucun service en ligne, aucune file d'attente, aucun filigrane.
    • Ce que vous voyez est ce que vous obtenez. L'export fidèle filme le navigateur image par image : pas de saccade, même sur un ordinateur modeste.
    • Un son propre. Le niveau sonore est vérifié à l'export ; la musique se baisse d'elle-même sous la voix.
    • Un export interrompu n'est pas perdu. Les parties déjà faites sont reprises au prochain export.

    Comment la lancer

    /pulse-motion:exporter

    Elle ne prend rien après le nom, mais vous pouvez préciser ce que vous voulez en le disant :

    Vous ditesPulse Motion exporte
    (rien)Il vous demande à quoi sert la vidéo : pour le web (recommandé), les réseaux sociaux, un courriel ou une réunion. Une vidéo verticale ou faite pour les réseaux propose d'abord les réseaux.
    « pour YouTube », « pour mon site », « pour notre plateforme de formation »Pour le web : la qualité de l'aperçu.
    « pour LinkedIn », « pour Instagram »Pour les réseaux sociaux : un peu plus nette, pour résister à la recompression des plateformes.
    « pour la projeter », « pour PowerPoint »Pour la présentation : très nette, lue par PowerPoint et Keynote.
    « pour mon monteur », « la meilleure qualité »Le master : le fichier le plus fidèle, à retravailler.
    « par courriel », « moins de 20 Mo »Une version légère, qui tient sous la taille dite (10 Mo sans précision).
    « vite fait, juste pour vérifier »Une version de travail, petite et rapide, à ne pas publier.
    « plus fluide »En 60 images par seconde. L'export prend deux fois plus de temps.
    « une version de travail avec la voix de l'ordinateur »Avec la voix provisoire, seulement si vous le demandez.
    « juste la scène 3 », « en GIF », « dans un téléphone », « un PDF des scènes »Les autres sorties (voir le tableau plus haut).
    « un texte pour accompagner la vidéo »Pulse Motion écrit sortie/<titre>-textes.md ; il vous le propose de lui-même après un export pour les réseaux ou le courriel.

    Avant de lancer, Pulse Motion vous dit combien de temps cela prendra ; pendant l'export, il suit le temps restant.

    Pulse Motion termine par un résumé : l'usage, la durée, le poids du fichier, le son (ou « muette »), le mode d'export, et chaque fichier avec son rôle.

    Risques et précautions

    • Les erreurs passent d'abord. S'il reste des erreurs, Pulse Motion vous les dit simplement et propose de les corriger d'abord avec /pulse-motion:retoucher. Les simples alertes n'empêchent pas l'export : il vous les mentionne en une phrase.
    • La voix provisoire est refusée. Si une scène parle encore avec la voix de l'ordinateur, Pulse Motion vous propose d'enregistrer d'abord votre voix. Il exporte avec la voix provisoire seulement si vous choisissez « une version de travail ».
    • ffmpeg n'est installé qu'avec votre accord, et seulement avec la commande officielle de votre système (winget sous Windows, Homebrew sous macOS).
    • Aucun fichier incomplet. Si l'export échoue, aucun MP4 à moitié écrit ne reste dans sortie/. Une version pour le courriel qui dépasserait la taille annoncée n'est jamais écrite.
    • Une scène en erreur arrête l'export. Si le script d'une scène échoue pendant l'export, Pulse Motion s'arrête et vous dit laquelle, et vers quel instant.

    Attention : un flash de plus de trois fois par seconde sur une grande partie de l'image est une erreur, pas une alerte : il peut déclencher une crise d'épilepsie. Pulse Motion vous propose de l'adoucir avant d'exporter.

    Problèmes et solutions

    « Chrome ou Edge introuvable »

    L'export a besoin de l'un des deux. Installez Chrome ou Edge (voir les prérequis). Autre solution : ouvrez l'aperçu dans l'un des deux et cliquez sur le bouton MP4 de la barre de lecture.

    La vidéo est exportée muette, ou sans la musique

    Un fichier son était illisible. Pulse Motion vous le dit dans un avertissement : la vidéo est exportée sans la source abîmée. Redonnez le fichier (musique ou voix), puis relancez l'export.

    L'export a été fait « dans le navigateur » alors que je voulais l'export fidèle

    ffmpeg n'était pas installé, ou sa version est trop ancienne. Pulse Motion vous propose de l'installer pour la prochaine fois. Voir ffmpeg.

    L'export s'est arrêté au milieu

    Relancez simplement /pulse-motion:exporter : les parties déjà faites sont reprises.

    Le fichier est trop lourd pour un courriel

    Demandez « une version pour l'envoyer par courriel » : elle tient sous 10 Mo, ou sous la taille que vous dites. Si la vidéo est trop longue, Pulse Motion vous propose une taille plus grande ou une seule scène.

    « Un export de cette vidéo est déjà en cours »

    Un autre export de la même vidéo tourne encore (le message dit depuis quelle heure) : attendez sa fin, puis relancez.

    Exemples

    /pulse-motion:exporter

    pulse-motion controler .

    La vidéo est prête à exporter. Une alerte : un texte de la scène 4 est un peu près du bord, sans gravité. ffmpeg est un petit logiciel libre qui fabrique la vidéo en haute qualité, avec un son propre ; il s'installe une fois. → Installer ffmpeg (Recommandé) / Exporter sans, dans le navigateur

    Installer ffmpeg

    winget install --id Gyan.FFmpeg -e --accept-source-agreements --accept-package-agreements

    À quoi va servir la vidéo ? → Pour le web (Recommandé) / Pour les réseaux sociaux / Pour l'envoyer par courriel / Pour la projeter en réunion

    Pour le web

    pulse-motion exporter . --pour web

    ✅ Fait : la vidéo « La chaîne du froid » est exportée en MP4 pour le web (1 min 04, avec le son, export fidèle). 📄 Fichiers : sortie/la-chaine-du-froid.mp4 (à publier), la page animée et les sous-titres .srt et .vtt.

    /pulse-motion:exporter

    La vidéo parle encore avec la voix de l'ordinateur, qui sert seulement à caler l'animation. → Enregistrer ma voix d'abord (Recommandé) / Exporter une version de travail avec la voix de l'ordinateur

    Enregistrer ma voix d'abord

    Dans l'aperçu, cliquez sur « Voix » : le texte défile, vous parlez, vous réécoutez, vous gardez ou refaites. Relancez ensuite /pulse-motion:exporter.

    Commandes liées

    • /pulse-motion:retoucher : corriger avant d'exporter, puis exporter de nouveau.
    • /pulse-motion:creer : la prochaine vidéo.
