À tout moment

Je suis bloqué

Une commande qui n'apparaît pas, un aperçu muet, un export qui refuse : presque tout se règle en une phrase. Cherchez votre situation ci-dessous, avec vos mots.

Les 4 réflexes qui évitent la plupart des blocages :

  1. Une vidéo = un dossier. Ouvrez toujours le dossier de la vidéo dans VS Code, pas celui qui le contient.
  2. Relancez après une installation. Claude Code lit la liste des logiciels à son démarrage : après avoir installé Node.js, Chrome, ffmpeg ou Python, fermez complètement VS Code et rouvrez-le.
  3. Chrome ou Edge pour l'aperçu. La voix et le bouton MP4 n'y marchent qu'avec eux.
  4. « annule » existe. Une retouche ratée se défait d'un mot.

Si vous ne savez pas quelle commande taper, décrivez simplement votre problème à Claude, avec vos mots : il connaît Pulse Motion et vous orientera. Pour reprendre le fil d'une vidéo, /pulse-motion:reprendre vous dit toujours où elle en est.

À l'installation

Les commandes /pulse-motion:… n'apparaissent pas

Le plugin n'est pas installé, ou Claude Code n'a pas été relancé. Tapez /plugins : pulse-motion doit apparaître dans l'onglet Plugins, avec son interrupteur activé. Sinon, suivez l'étape Installer Pulse Motion, puis fermez complètement VS Code et rouvrez-le.

« node » introuvable, ou « Node.js est trop ancien »

Pulse Motion demande Node.js 20 ou plus. Installez la version LTS depuis nodejs.org (voir les prérequis), puis fermez complètement VS Code et rouvrez-le. Tant que la version est trop ancienne, Pulse Motion vous le rappelle au début de chaque session.

« Chrome ou Edge introuvable »

Installez l'un des deux (sous Windows, Edge est déjà là). S'il est installé à un endroit inhabituel, indiquez son chemin dans la variable d'environnement PM_NAVIGATEUR ; demandez à Claude de vous guider. Voir Chrome ou Edge.

Pendant la création

« Une vidéo existe déjà ici »

Le dossier contient déjà un déroulé. Pour continuer cette vidéo : /pulse-motion:reprendre. Pour une nouvelle vidéo : créez un autre dossier vide, ouvrez-le, puis relancez /pulse-motion:creer.

« Aucune vidéo ici » alors que j'en ai une

Le dossier ouvert n'est pas celui de la vidéo : il doit contenir deroule.json. Ouvrez le bon dossier avec File → Open Folder….

La conversation s'est arrêtée au milieu

Rien n'est perdu : l'état de la vidéo est dans son dossier. Lancez /pulse-motion:reprendre.

Mon logo ne donne pas de bonnes couleurs

Donnez un PNG ou un SVG plutôt qu'un JPEG. Si le logo est en noir et blanc, il n'a pas de couleur exploitable : dites vos couleurs en mots (« bleu marine et orange »). Après coup : « mets mes couleurs : bleu marine et orange » avec /pulse-motion:retoucher.

Ma police n'a pas été trouvée

Pulse Motion cherche dans les polices gratuites de Bunny Fonts. Si la vôtre n'y est pas, il garde la plus proche des polices du style. Donnez-lui le fichier de votre police (.ttf, .otf, .woff ou .woff2) : il vérifie qu'elle contient les caractères français.

« Le rendu n'a pas pu être vérifié »

Ni Chrome ni Edge n'ont été trouvés, ou la page a rencontré une erreur. La vidéo est fabriquée, mais les contrôles à l'image n'ont pas été faits. Installez l'un des deux navigateurs, puis demandez une retouche : le contrôle complet se refait.

Dans l'aperçu

L'aperçu ne s'est pas ouvert, ou je l'ai fermé

Demandez « rouvre l'aperçu » à Claude, ou lancez /pulse-motion:reprendre. L'aperçu est servi depuis votre ordinateur, à une adresse en http://localhost:….

Je n'entends rien

Les navigateurs attendent un geste de votre part avant de jouer un son : cliquez sur ▶. Vérifiez le volume de l'ordinateur et de l'onglet. Si la vidéo n'a pas de musique ni de voix, elle est muette : c'est voulu.

L'aperçu ne s'est pas mis à jour après une retouche

Il se recharge seul tant qu'il est ouvert depuis Pulse Motion. Sinon, rechargez la page (F5, ou Cmd + R sur Mac).

Je ne trouve pas le bouton « Voix » ou « MP4 »

Ils sont dans la barre de lecture de l'aperçu, pas dans la page animée de sortie/. Ouvrez l'aperçu (adresse en http://localhost:…) dans Chrome ou Edge.

« Effet non affiché : WebGPU indisponible »

Les effets de particules (étincelles, confettis…) et l'atelier des effets demandent WebGPU, plus récent que le WebGL des fonds animés de beaucoup de sites : un site qui affiche bien ses shaders ne prouve donc pas que WebGPU marche. Le plus simple : ouvrir la même adresse dans Chrome ou Edge récent (Edge est déjà là sous Windows).

Dans un autre navigateur basé sur Chromium (Opera, Brave, Vivaldi…), WebGPU peut être activé mais la carte graphique refusée. Pour savoir ce qui bloque, ouvrez la console (F12, onglet « Console ») sur la page de l'aperçu et collez :

console.log('gpu :', !!navigator.gpu); console.log('carte :', await navigator.gpu?.requestAdapter());
  • gpu : false : WebGPU n'est pas proposé. Activez « Unsafe WebGPU Support » dans la page des fonctions expérimentales (opera://flags/#enable-unsafe-webgpu sous Opera), puis redémarrez le navigateur.
  • carte : null : la carte graphique est refusée. Le même réglage lève ce refus ; vérifiez aussi que l'accélération matérielle est activée dans les réglages du navigateur, et que la ligne « WebGPU » de opera://gpu (ou chrome://gpu) indique « Hardware accelerated ». Sinon, mettez à jour le pilote de la carte graphique.
  • Une carte s'affiche : rechargez la page (Ctrl + F5).

Avec la voix

« Ce navigateur ne sait pas enregistrer »

L'aperçu est ouvert dans Firefox ou Safari. Copiez son adresse dans Chrome ou Edge. Autre solution : enregistrez avec votre propre logiciel et donnez le fichier à Pulse Motion.

« La prise semble vide »

Le studio n'a entendu que du silence, un souffle ou un clic. Vérifiez le micro choisi dans les réglages du son de l'ordinateur, et l'autorisation du micro (icône dans la barre d'adresse du navigateur). Puis recommencez, en parlant au moins une seconde.

La vidéo parle avec une voix d'ordinateur

C'est la voix provisoire, qui cale l'animation en attendant la vôtre. Dans l'aperçu, cliquez sur Voix et enregistrez les scènes marquées « voix provisoire ». Voir la voix.

« Aucune voix du système »

L'ordinateur n'a pas de voix française pour la voix provisoire. Ce n'est pas bloquant : les sous-titres se répartissent sur la scène en attendant votre enregistrement.

La transcription ne s'installe pas

Elle demande Python. Sous Windows, un Python tout juste installé n'est visible qu'après un redémarrage de Claude Code : fermez complètement VS Code, rouvrez-le, et demandez « installe la transcription ». Si elle échoue encore, continuez sans : les mots sont calés au mieux, tout fonctionne.

Mon enregistrement de toute la vidéo est refusé

Le découpage par scène demande la transcription. Installez-la (Pulse Motion vous le propose), puis redonnez le fichier. Sinon, enregistrez scène par scène dans le studio.

« Scène mal reconnue » à l'import de ma voix

Dans cette scène, moins de la moitié des mots du texte ont été reconnus : le découpage est peut-être décalé. Écoutez-la dans l'aperçu ; si besoin, réenregistrez-la seule : « je réenregistre la scène 4 ».

À l'export

L'export s'arrête sur la voix provisoire

Pulse Motion refuse d'exporter la voix de l'ordinateur sans votre accord. Enregistrez votre voix d'abord, ou répondez « Exporter une version de travail avec la voix de l'ordinateur ».

Pulse Motion me propose de corriger des erreurs avant d'exporter

Le contrôle a trouvé une erreur (un texte qui déborde, un flash, un son introuvable…). Acceptez la correction proposée, ou demandez-la avec /pulse-motion:retoucher, puis relancez l'export. Les simples alertes, elles, n'empêchent pas l'export.

L'export a été fait « dans le navigateur »

ffmpeg n'est pas installé, ou sa version est trop ancienne. Le MP4 est valable ; pour l'export fidèle la prochaine fois, acceptez l'installation de ffmpeg ou suivez les prérequis.

La vidéo exportée est muette, ou il manque la musique

Un fichier son était illisible : Pulse Motion l'a dit dans un avertissement, et a exporté sans lui. Redonnez le fichier, puis relancez l'export.

L'export s'est interrompu

Relancez /pulse-motion:exporter : les parties déjà faites sont reprises. Aucun fichier incomplet n'a été écrit.

Le MP4 est trop lourd

Relancez l'export en demandant « une version plus légère » : il passe en 720p.

Je ne retrouve pas le fichier MP4

Il est dans le dossier sortie/ de la vidéo, sous le titre écrit en minuscules, sans accents ni espaces : « La chaîne du froid » donne la-chaine-du-froid.mp4.

Avec les retouches

La retouche a changé autre chose que ce que je voulais

Dites « annule », puis reformulez en précisant la scène et l'élément : « dans la scène 3, seulement le titre ».

« Aucune retouche à annuler »

Vous êtes revenu au plus ancien état gardé (les 20 dernières retouches sont conservées), ou la vidéo n'a jamais été retouchée.

J'ai demandé une durée précise, et Pulse Motion signale un problème de lecture

Il respecte votre durée et vous prévient simplement que le texte risque d'être lu trop vite. Gardez votre durée, ou raccourcissez le texte.

Après un changement de style, une scène est différente

C'était une scène composée librement : elle a été réécrite dans le nouveau style. Décrivez ce qui vous manque (« remets le personnage à gauche »), ou dites « annule » pour revenir à l'ancien style.

Avec les personnages

Je ne trouve pas la commande /pulse-motion:dessiner-personnage

Votre plugin n'est pas à jour : les personnages sont arrivés dans les versions récentes. Tapez ces deux commandes dans Claude Code, une à la fois :

/plugin marketplace update pulse-motion
/plugin update pulse-motion@pulse-motion

Puis fermez complètement Claude Code et relancez-le : les commandes /pulse-motion:dessiner-personnage, /pulse-motion:animer-personnage, /pulse-motion:atelier-personnages et /pulse-motion:decouper-personnage apparaissent.

La tête flotte au-dessus du corps, ou un élément manque dans une vue

Le dessin n'est pas le même d'une vue à l'autre : le cou ne rejoint pas la tête de face, ou la toque n'existe que de profil. Dites ce que vous voyez, par exemple :

/pulse-motion:dessiner-personnage redessine sa tête de face

Pulse Motion reprend la vue fautive et compare à nouveau les vues entre elles.

Le personnage cache un texte

Faites-le entrer par le côté, rendez-le plus petit, ou faites-lui traverser la scène avant l'arrivée du texte : « fais entrer le cuisinier par la droite », « rends-le plus petit ». Voir un personnage dans une scène.

Un mouvement ne ressemble pas à ce que j'ai demandé

Demandez à le voir : « montre-moi le salut de face et de profil ». Sur la planche, dites ce qui ne va pas (« la main doit monter plus haut »). Pour le régler vous-même, ouvrez /pulse-motion:atelier-personnages : glissez les articulations, puis Enregistrer.

Le personnage glisse pendant une pose ou un geste

La pose a été placée pendant sa marche. Demandez qu'elle commence après la fin de la marche : « qu'il montre le chiffre une fois arrivé ».

« La scène n'a pas de voix »

Un personnage ne peut parler que dans une scène qui a un texte dit. Ajoutez le texte que la voix dit dans cette scène (« ajoute un texte dit à la scène 2 : … »), ou retirez la parole de ce personnage. Voir la voix.

Le personnage reste bouche fermée alors qu'il doit parler

Deux causes possibles, que Pulse Motion vous signale :

  • la voix de la scène n'est pas encore enregistrée : enregistrez-la dans le studio (bouton Voix de l'aperçu), ou demandez une voix provisoire en attendant ;
  • le dessin n'a pas de bouches de parole : demandez « dessine-lui les bouches pour parler » avec /pulse-motion:dessiner-personnage.
Mon illustration est refusée à la découpe

Elle contient du texte, une image collée, une copie liée, un filtre ou un masque. Pulse Motion vous dit quoi changer dans votre logiciel de dessin ; le détail est sur la page animer votre illustration.
